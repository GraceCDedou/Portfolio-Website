# Grace Dedou Portfolio

Hi, I'm Grace. This is my personal portfolio website. I'm a student learning web development, programming and UI/UX design, and I built this site to show who I am and what I've worked on so far. I'm still early in my journey, and I'm looking for an internship or an entry level role where I can keep learning.

The site has six sections: Home, About Me, Services, Skills, Projects and Contact.

## Live Website

You can see the site here: https://github.com/GraceCDedou

## What I Used to Build It

I kept things simple and used the basics:

* **HTML** for the structure of the page and all the content.
* **CSS** for the layout, colours, fonts, spacing, the light and dark theme, and making the site fit different screen sizes.
* **JavaScript** for the typing effect on the home section, the theme toggle and the navigation.

I didn't use any frameworks or libraries. I'm also learning React and Git at the moment, but they aren't part of this site yet.

Other tools that helped me along the way:

* **Visual Studio Code** to write the code.
* **Figma** to design and prototype my UI/UX project.
* **Git and GitHub** to save my work and host the site with GitHub Pages.

## Features

Here's what you'll find on the site:

* A navigation bar that links to every section and underlines the one you're on.
* A home section with a short intro, my photo, and a typing animation.
* A small note that says I'm open to internships and entry level roles.
* A theme toggle button, so you can switch between light mode and dark mode.
* An About Me section called "My Story", with a short bio and a timeline of where I am now and how I got here.
* A Services section with cards for UI/UX Design, Frontend Development, Wireframing and Prototyping, Responsive Layouts, Problem Solving and Fast Learning.
* A Skills section that shows the languages I code in and how I like to work.
* A Projects section with cards for my work, each with tags and a link.
* A Contact section with my details and a contact form where you can leave your name, email, subject and message.
* A layout that adjusts to different screen sizes.

## How to Run It on Your Computer

You'll need Git and a web browser like Chrome, Firefox or Edge.

1. Open your terminal and copy the project with this command:

```
git clone https://github.com/GraceCDedou/Portfolio-Website.git
```

2. Go into the project folder:

```
cd https://github.com/GraceCDedou/Portfolio-Website.git
```

3. Open the file called index.html in your browser. You can double click it, or right click it and choose "Open with" and pick your browser.

If you use Visual Studio Code, you can also install the Live Server extension, right click index.html and choose "Open with Live Server".
